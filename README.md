Что изучено
1. Индексация массивов
В C# нумерация элементов начинается с нуля: первый элемент имеет индекс [0], последний — [длина − 1]. Поэтому в формулах часто используется Length - 1, например при развороте массива arr[arr.Length - 1 - i].

2. Когда нужен foreach
Этот цикл удобен, когда массив нужно только прочитать: вывести на экран, посчитать сумму, найти минимум и максимум, подсчитать чётные числа. Он сам перебирает все элементы, и не нужно следить за индексом.

3. Когда нужен for
Цикл for применяется, когда важен индекс или нужно изменить элементы массива: заполнить массив с клавиатуры (grades[i] = ...) или поменять местами пары при развороте «на месте». В foreach записывать в элемент нельзя — переменная итерации доступна только для чтения.
